## Project Overview
This project uses Scrapy to scrape book information from the Books to Scrape website. The collected data is cleaned, analyzed, visualized, and enhanced using feature engineering techniques.

## Files Included
- `202618018_lab_1.ipynb` – Jupyter Notebook containing the complete analysis
- `books.csv` – Raw scraped dataset
- `books_cleaned.csv` – Cleaned dataset
- `bookscraper/` – Scrapy project and spider files
- `scrapy.cfg` – Scrapy configuration file

## Libraries Used
- Scrapy
- Pandas
- Matplotlib
- WordCloud

## Visualizations
- Distribution of Book Ratings
- Average Price by Category
- Stock Availability by Category
- Word Cloud of Book Descriptions

## Output
The project demonstrates web scraping, data cleaning, exploratory data analysis (EDA), visualization, and feature engineering.
